# Simple Interest Calculator — V2

A more structured version of the Simple Interest Calculator written in C.

## Improvements Over V1

- Uses functions for separation of logic
- Uses a struct to organize data
- Uses pointers to modify data across functions
- Cleaner and more maintainable code structure

## Concepts Used

- Structs
- Functions
- Pointers
- `switch` statements
- Modular program design

## Program Flow

1. Collect user input
2. Convert time into years
3. Calculate interest
4. Display final result

## Compilation

```bash
gcc -Wall -Wextra -Wpedantic main.c -o calculator
```

## Running

```bash
./calculator
```
